Track A: Continuous Optimization

1. Problem Statement

Continuous optimization lies at the foundation of machine learning, non-linear regression, and engineering physics. This track evaluates how first-order optimizers (with adaptive learning rates and momentum), second-order methods (incorporating Hessian curvature), and curvature approximations navigate diverse objective landscapes.

2. Mathematical Formulation

Given objective function $f: \mathbb{R}^d \to \mathbb{R}$:

  • Standard Gradient Descent: $x_{t+1} = x_t - \eta \nabla f(x_t)$
  • Momentum: $v_{t+1} = \gamma v_t + \eta \nabla f(x_t), \quad x_{t+1} = x_t - v_{t+1}$
  • Nesterov Accelerated Gradient (NAG): $v_{t+1} = \gamma v_t + \eta \nabla f(x_t - \gamma v_t), \quad x_{t+1} = x_t - v_{t+1}$
  • Adam: Updates biased first ($m_t$) and second ($v_t$) moments with bias correction: $$\hat{m}_t = \frac{m_t}{1 - \beta_1^t}, \quad \hat{v}t = \frac{v_t}{1 - \beta_2^t}, \quad x{t+1} = x_t - \frac{\eta}{\sqrt{\hat{v}_t} + \epsilon} \hat{m}_t$$
  • Newton's Method with Levenberg-Marquardt Spectral Regularization: $$x_{t+1} = x_t - [H(x_t) + \lambda I]^{-1} \nabla f(x_t)$$
  • Gauss-Newton Method: For non-linear least squares $f(x) = \frac{1}{2} |r(x)|2^2$, approximates Hessian via Jacobian outer product $H \approx J^T J$: $$x{t+1} = x_t - [J(x_t)^T J(x_t) + \lambda I]^{-1} J(x_t)^T r(x_t)$$

Track B: Discrete Optimization & QUBO

1. Problem Statement

Discrete optimization addresses combinatorial problems where decision variables are constrained to integer or binary domains. This track compares exact tree search, dynamic programming, and mathematical programming against greedy heuristics on the 0-1 Knapsack problem, and explores quadratic unconstrained binary optimization (QUBO) with Ising spin conversions.

2. Mathematical Formulation

  • 0-1 Knapsack ILP: $$\max \sum_{i=1}^n v_i x_i \quad \text{subject to } \sum_{i=1}^n w_i x_i \le W, \quad x_i \in {0, 1}$$
  • QUBO Mapping with Binary Slack Variables: To encode inequality $\sum w_i x_i \le W$, slack integer $s \in [0, W]$ is expanded into $K = \lfloor \log_2 W \rfloor + 1$ binary variables $s = \sum_{k=0}^{K-1} 2^k y_k$: $$H_{\text{QUBO}}(x, y) = - \sum_{i=1}^n v_i x_i + P \left( \sum_{i=1}^n w_i x_i + \sum_{k=0}^{K-1} 2^k y_k - W \right)^2$$ where penalty multiplier $P > \max_i v_i$ guarantees that any infeasible assignment incurs higher energy than the optimal feasible solution.
  • Ising Spin Transformation: Mapping binary $x_i \in {0, 1}$ to spin $s_i \in {-1, +1}$ via $x_i = \frac{1 - s_i}{2}$.

Track C: Quantum Optimization

1. Problem Statement

Quantum optimization investigates variational hybrid algorithms executed on quantum processing units (QPUs). This track implements QAOA, VQE, analytical parameter-shift gradients, SPSA, and Fubini-Study Quantum Natural Gradient (QNG), and investigates hardware-induced barriers (Barren Plateaus, shot noise, depolarizing errors).

2. Mathematical Formulation

  • QAOA Circuit ($p$ Layers): $$|\gamma, \beta\rangle = \prod_{l=1}^p \left( e^{-i \beta_l \sum X_i} e^{-i \gamma_l C} \right) |+\rangle^{\otimes n}$$
  • Parameter-Shift Rule (Exact Analytical Circuit Gradient): $$\frac{\partial \langle H \rangle}{\partial \theta_j} = \frac{\langle H \rangle_{\theta_j + \frac{\pi}{2}} - \langle H \rangle_{\theta_j - \frac{\pi}{2}}}{2}$$
  • Barren Plateau Gradient Variance Decay: $$\text{Var}_{\theta}\left[ \frac{\partial \langle H \rangle}{\partial \theta_j} \right] \in \mathcal{O}\left( 2^{-n} \right)$$

Track D: Submodular, Parallel and Distributed Optimization

1. Problem Statement

Evaluates combinatorial set optimization with diminishing returns, multi-core parallel scaling, distributed client training with federated averaging, and multi-objective/multi-task gradient balancing.

2. Mathematical Formulation

  • Submodular Diminishing Returns: $$f(A \cup {e}) - f(A) \ge f(B \cup {e}) - f(B) \quad \forall A \subseteq B, ; e \notin B$$ Greedy selection achieves approximation factor: $$f(S_{\text{greedy}}) \ge \left( 1 - \frac{1}{e} \right) f(S^) \approx 0.6321 \cdot f(S^)$$
  • Amdahl's and Gustafson's Laws: $$\text{Amdahl: } S(P) = \frac{1}{s + \frac{1 - s}{P}}, \quad \text{Gustafson: } S(P) = P - s(P - 1)$$
  • Multiple Gradient Descent Algorithm (MGDA): $$\min_{\alpha \in \Delta^m} \left| \sum_{i=1}^m \alpha_i \nabla f_i(x) \right|_2^2 \quad \text{s.t. } \sum \alpha_i = 1, ; \alpha_i \ge 0$$
  • GradNorm Dynamic Task Balancing: $$L_{\text{grad}}(w; t) = \sum_{i=1}^T \left| G_W^{(i)}(t) - \bar{G}_W(t) [r_i(t)]^\alpha \right|$$

Track F: Compiler Optimization

1. Problem Statement

Evaluates code size reduction and execution speedup on intermediate representations (3AC) through five classical compiler passes run to fixed-point convergence, combined with Binary Integer Linear Programming (BILP) for budget-constrained pass selection.

2. Mathematical Formulation & Compiler Passes

  1. Constant Folding (CF): Evaluates binary operations on literal constants at compile time ($3 + 5 \to 8$).
  2. Constant Propagation (CP): Replaces variable uses with known constants along reaching definition paths.
  3. Strength Reduction (SR): Replaces expensive arithmetic operations with cheaper equivalents ($x \times 2 \to x + x, x \times 0 \to 0$).
  4. Common Subexpression Elimination (CSE): Reuses previously computed values within basic blocks ($t_1 = a + b; t_2 = a + b \to t_2 = t_1$).
  5. Dead Code Elimination (DCE): Eliminates assignments to variables whose values are never subsequently read.
  6. Pass Selection BILP Model: $$\max_{x \in {0, 1}^m} \sum_{i=1}^m \left( w_{\text{rt}} B_i^{\text{rt}} + w_{\text{sz}} B_i^{\text{sz}} - w_{\text{cmp}} C_i^{\text{cmp}} \right) x_i \quad \text{s.t. } \sum_{i=1}^m C_i^{\text{cmp}} x_i \le C_{\text{budget}}, \quad x_{\text{CF}} \le x_{\text{CP}}$$

Track G: xv6 Operating-System Feature Modification & Optimization

1. Problem Statement

The official MIT xv6 teaching operating system lacks per-process CPU time accounting. Without CPU time accounting, the OS scheduler cannot compute thread utilization, enforce fair-share scheduling, or report resource usage to user space.

2. Kernel Modification & System Call Design

  • Process Structure Extension (kernel/proc.h): Added uint64 cputime; to struct proc. Initialized to 0 in allocproc() and reset in freeproc().
  • Hardware Timer Trap Instrumentation (kernel/trap.c): In both usertrap() and kerneltrap(), charged timer ticks strictly to the currently executing process upon device timer interrupts (which_dev == 2):
    if (which_dev == 2) {

  yield();
}
  • New System Call (sys_getcputime, syscall 23): Exposed getcputime() returning uint64 with process lock synchronization (acquire(&p->lock)).

3. Chapter 6 Optimization Architecture

  1. Backward Dynamic Programming for Critical Path Potentials: $$V(i) = d_i + \max_{j \in \text{Children}(i)} V(j), \quad V(\text{leaf}) = d_{\text{leaf}}$$ Evaluated in reverse topological order in a single $O(V+E)$ pass. Priority queries become $O(1)$ lookups.
  2. Incremental In-Degree Tracking: Decrements child in-degrees strictly when parents complete ($O(E)$ total).
  3. Priority-Queue Event Scheduling: Binary min-heap ordered by $(-p_i, -V(i), i)$ and worker timeline heap of size $W$, reducing complexity to $O((V+E)\log V)$.
